# A Windows 10 Simulator made in Godot

This project is incomplete and may or may not receive updates in the future.

# Features

- Accurate Boot Screen
- Extremely accurate login screen (Password is `GodotWindows`)
- Bare-bones Notepad app and desktop
- Visual Search bar
- Working clock

# Not working

- WiFi Button in Login Screen
- F2 doesn't open BIOS (intentional)
- Desktop Start Button and Search bar and Show Desktop button doesn't work.
- Notepad Menu bar and Status bar is static

Made in Godot Game Engine on Windows 10
